# Example: New API Endpoint

**Prompt:**
"Add a GET endpoint at /api/v1/users/:id that returns user details"

**Result:**
The API Builder agent will create:
- Route definition in src/routes/user.routes.ts
- Controller method in src/controllers/user.controller.ts
- Service method in src/services/user.service.ts
- Type definitions if needed

The code will follow your project's conventions automatically.
